# Vocal-Remover (Subject to change)
Topics in Modern Software Engineering

## Pitch
This project is a vocal removal tool that allows users to separate vocals and instrumentals from a song when an official instrumental version is unavailable. Users upload an audio file and select whether they want to extract the vocal track, the instrumental track, or both. This is intended for creative uses such as karaoke creation, sampling, remixing, etc.

## Project Description
The vocal remover is designed to provide a straightforward way for users to separate audio without requiring advanced technical knowledge or professional audio software. The system would process uploaded audio files and apply established audio processing techniques to distinguish vocals from background music. After processing, users would preview and download the separated tracks in common audio formats. The focus is on clarity of results and ease of use rather than perfect studio-quality separation.

The goal of the project is to emphasize usability, efficiency, and a simple workflow. Instead of targeting professional audio engineers, the tool is aimed at students, hobbyists, and content creators who need quick and practical results. The project could be extended with additional features such as format support, batch processing, or adjustable separation settings. Overall, the system is intended as a flexible audio-processing application.

## Primary Users
* Karaoke enthusiasts
* Music producers and remixers
* Content creators
* Students and hobbyists working with audio samples

## Features
* Upload audio files in common formats (MP3, WAV, maybe OGG)
* Separate vocals from instrumentals
